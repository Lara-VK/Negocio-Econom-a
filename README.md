# Marketplace Estudiantil — Proyecto IF6200

Este repositorio contiene el frontend inicial (React + Vite) para un Marketplace digital orientado a estudiantes universitarios.

Objetivo: crear una aplicación web donde estudiantes puedan publicar y comercializar productos y servicios dentro de una comunidad universitaria.

Instalación y ejecución (PowerShell en Windows):

```powershell
npm install
npm run dev
```

Estructura inicial generada por el asistente:

- `index.html` — plantilla base
- `package.json` — dependencias y scripts
- `vite.config.js` — configuración Vite
- `src/` — código fuente React (App, páginas, componentes)
- `src/styles/global.css` — estilos básicos

Siguientes pasos recomendados:

- Implementar backend/API (autenticación, base de datos)
- Formularios para publicación de productos y gestión de usuarios
- Integrar sistema de pagos o enlaces externos
- Añadir tests y despliegue

Descripción del proyecto (resumen):

Se propone el desarrollo de un Marketplace digital exclusivo para emprendimientos estudiantiles que permita a los universitarios publicar, promocionar y comercializar sus productos o servicios dentro de un entorno seguro, accesible y de bajo costo. El proyecto busca fomentar la cultura emprendedora, incentivar la cooperación entre estudiantes y generar un impacto económico positivo en el ámbito académico.

Para más detalles del anteproyecto (introducción, problema, marco teórico), ver la página interna de la aplicación una vez que inicie el servidor de desarrollo.
